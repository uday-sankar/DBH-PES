# DBH-PES
A Potential Energy surface for the unimolecular Diazacycloheptene denitrogenation reaction
Based on the Work by Lionel M. Raff et, al. https://doi.org/10.1063/1.468990
## 
- Main Driver: Full_V.jl
- A geometry minimization test: Optimizer.jl
- Other .jl files are sub potential which Full_V.jl calls
- .ods files contain the parameters for the PES
